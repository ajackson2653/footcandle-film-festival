# Sponsor logos

Drop each sponsor's logo image file in this folder.

For each sponsor, I need three things (four if you use tiers):

1. **Sponsor name** (for the logo's alt text / accessibility)
2. **Website URL** (the logo links here)
3. **Logo file** — placed in this folder
4. **Tier** (optional) — e.g. Festival / Director / Producer / Star / Crew

**File tips**
- Formats: SVG (best — crisp at any size), or PNG/JPG. Transparent PNG preferred.
- Name files simply after the sponsor, e.g. `acme-hardware.png`, so they're easy to match to the list.
- Any size is fine; I'll optimize. Each logo is displayed on a white tile so
  logos of any color read consistently on the site's dark background.
